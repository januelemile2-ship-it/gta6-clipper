# GTA Clipper

Outil personnel qui repère des moments forts de lives de jeux vidéo, les monte en vidéos verticales
(titre, sous-titres, écran de fin) et les dépose sur la chaîne YouTube de son propriétaire.

- Usage strictement personnel : l'outil n'est pas proposé au public et n'a qu'un seul utilisateur, son propriétaire.
- Il n'envoie des vidéos que sur la chaîne YouTube du propriétaire, avec son autorisation (accès « youtube.upload »).
- Les clips citent le streamer d'origine.

Politique de confidentialité : voir [PRIVACY.md](PRIVACY.md).
